# Personal Radar — Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Personal intelligence agent: multi-source collectors → dedup → LLM ranking → daily Telegram briefing → feedback loop.

**Architecture:** Single Go process, worker-per-collector, unified `Item` model, PostgreSQL persistence, staged LLM pipeline (filter → rank → synthesis) via OpenCode Go API. Connectors behind a `Collector` interface so the pipeline never knows the source.

**Tech Stack:** Go 1.24, PostgreSQL 17, Docker Compose, `gofeed` (RSS/Atom), `golang.org/x/oauth2` (Reddit), `go-telegram-bot-api`, OpenCode Go API (minimax-m3 / deepseek-v4-flash / glm-5.3).

**Verified environment (2026-08-25):**
- Pi 5 aarch64, 4 cores, 8 GB RAM, Docker 29.7 + Compose v5.3, Go 1.24.4
- OpenCode Go: minimax-m3 ✓, deepseek-v4-flash ✓, glm-5.3 ✓ — **no /embeddings endpoint** → semantic dedup will use local shingle hashing + LLM fallback, not embeddings
- GitHub: `gh` authed (S1933), 5000 req/h ✓
- Telegram: **Radar needs its own bot token** (Hermes' bot is polled by the gateway — getUpdates conflict)
- Reddit: script-app OAuth, no secret yet

### Task 1.2: Collector interface + registry

**Files:** Create: `internal/collectors/collector.go`, `internal/collectors/registry.go`

```go
package collectors

import (
	"context"
	"time"

	"github.com/S1933/personal-radar/internal/item"
)

// Collector fetches items from a single source. Implementations must be
// safe for concurrent use and must return partial results alongside errors:
// one dead feed must not abort the whole collection run.
type Collector interface {
	Name() string
	// Collect fetches all items newer than since. Implementations log
	// per-feed/subreddit/repo errors and return what they got.
	Collect(ctx context.Context, since time.Time) ([]item.Item, error)
}
```

`registry.go`: `type Registry struct { collectors []Collector }` with `Register(Collector)`, `Run(ctx, since)` returning `(map[string]Result, error)` where `Result{Items, Collected, Failed, Err}` — runs all collectors in parallel with `errgroup`, records a `runs` row per collector per cycle. **No test for the registry itself in Phase 1** (exercised in integration below); unit tests on each collector's normalization.

**Commit:** `feat(collectors): Collector interface + concurrent registry`
